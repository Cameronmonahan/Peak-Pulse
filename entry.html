Data Entry

Peak Exposure Media — updates data.json directly in GitHub

Connection

Create a token at github.com/settings/personal-access-tokens/new — scope it to just this one repository, with Contents: Read and write permission only. Nothing else is needed.
How this works
This page reads clients.json and data.json/history.json directly from your repo, lets you edit the numbers, then commits the updated files back using GitHub's API — the same as if you'd edited them by hand on github.com. Your token is never saved anywhere except (optionally) this browser tab's session memory, and is never sent anywhere except directly to api.github.com.
