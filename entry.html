Data Entry

Peak Exposure Media — updates data.json, daily.json & weekly.json directly in GitHub

Connection

Create a token at github.com/settings/personal-access-tokens/new — scope it to just this one repository, with Contents: Read and write permission only.
How this works
Daily Update (do every day): follower count + whether you posted today. This builds a permanent day-by-day log (daily.json) that the dashboard uses for "new followers today," this week's post count, and monthly totals.

Weekly Engagement (do once a week, whenever convenient): total likes + comments across the last 5 posts. This is saved once per week (weekly.json) and used for the engagement rate shown on the dashboard — it does NOT need to be filled in every day.

Your GitHub token is never saved anywhere except (optionally) this browser tab's session memory.
